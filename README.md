# Portfólio — Eduardo Araújo

Site: https://eduaraujogh.github.io/portfolioedu/

Feito com [Astro](https://astro.build) e [Lenis](https://lenis.darkroom.engineering) (scroll suave).

## Rodar localmente

```bash
npm install
npm run dev
```

Abre em http://localhost:4321/portfolioedu/

## Onde editar

- `src/data/site.ts` — todos os textos, links e projetos
- `src/styles/tokens.css` — cores, tipografia, espaçamentos e movimento
- `src/components/` — seções do site

Cada push na branch `main` publica o site automaticamente (GitHub Actions → Pages).
